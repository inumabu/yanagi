# Roadmap

## Phase 1 — Foundation ✅

Node.js、TypeScript、discord.js、Redis、Docker、structured logging、Rate Limit、graceful shutdown、CI/CD、ドキュメントを提供します。

## Phase 2 — Discord features ⏳

Welcome、Audit Log、VC Log、VC 自動生成を追加します。permission、race condition、cleanup、監査ログを完了条件にします。

## Phase 3 — Economy ⏳

Points ledger、Omikuji、Prize、Lottery を追加します。Redis を正本にせず、永続データ層と transaction 方針を先に確定します。

## Phase 4 — Async services ⏳

TTS、AI、Queue、VOICEVOX、Retry、Idempotency を追加します。同期処理で Gateway をブロックしません。

## Phase 5 — Operations ⏳

Metrics、Alerting、Backup、Load test、Failure test、Zero-downtime deployment、Shard lifecycle を追加します。
